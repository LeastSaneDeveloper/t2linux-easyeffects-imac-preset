# t2linux-easyeffects-imac-preset
Based on the amazing work by [angelobdev!](https://github.com/angelobdev/t2-easyeffects-preset)

An EasyEffects preset for T2Linux iMacs, tested on a 27-inch iMac 2020.

I kind of forgot what changes I did to angelobdev's preset, but it has these effects:

Limiter -> Filter -> Bass Enhancer -> Multiband Compressor -> Stereo TOols -> Equalizer

# How to install
It depends on how you installed it.

## Installed via native package manager
Place the provided mbp.json in the directory ~/.config/easyeffects/output/

## Installed via Flatpak
Place the provided mbp.json in the directory ~/.var/app/com.github.wwmm.easyeffects/config/easyeffects/output/

## Manual installation
Go to Output -> Presets and to the right of "New preset name", click on "Import preset file", and select the provided mbp.json file (assuming you downloaded it).
